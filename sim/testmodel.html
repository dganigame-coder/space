OpenRouter Dynamic Model Waterfall

Discover available models, route each prompt intelligently, and fall back to other models when a request fails or produces a truncated answer.

Security notice: This standalone demo sends your API key directly from your browser to OpenRouter. The key is held only in page memory—not in localStorage or sessionStorage—and is cleared when the page is hidden or unloaded. For a public application, proxy API requests through your own server so the secret never reaches the browser. Never publish or commit a real key.
