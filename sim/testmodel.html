OpenRouter Dynamic Model Waterfall

Discover models, configure a fallback chain, and execute chat completions.

Security notice: This demo sends your API key directly from your browser to OpenRouter. Use a dedicated/restricted key when possible. Never publish a shared key or commit credentials to source control. For a public application, move the API call to your own server so the secret never reaches the browser.

1. Configure OpenRouter

The key is held in page memory and is not saved to local storage. Clearing or reloading the page removes it from this application's JavaScript state. Paste only the key itself (for example sk-or-v1-...); an optional Bearer prefix is also accepted and normalized automatically.
